# -----------------------------
# WORKFLOW
# -----------------------------

Teacher observes learning state
        ↓
Teacher proposes bucket mixture (chooses a probability distribution over these 5 buckets)
        ↓
Dirichlet perturbs mixture for exploration
        ↓
Batch gets constructed slot-by-slot
        ↓
Student learns
        ↓
Validation improvement computed
        ↓
Teacher gets reward
        ↓
REINFORCE updates teacher

note: a_t tells you the probability of choosing each bucket. 


# -----------------------------
# FULL HYPERPARAMETERS SUMMARY
# -----------------------------

Student θ   - update every step t 
Teacher φ   - once per episode  

# Experiment setup
episodes    = number of episodes 
T           = training steps per episode (short horizon to reduce variance)
seed        = number of seeds -> 1 seed = 1 full range of experiments (all episodes)

# Student (learner)
B           = training batch size
m           = validation batch size (fixed integer, not %)
η_student   = (eta) student learning rate

# Teacher (policy)
η_teacher   = (eta) teacher learning rate
γ           = (gamma) discount factor
λ_cost      = (lambda) compute-cost weight
α_reg       = (alpha) KL stability regularizer weight
p_ref       = reference distribution over buckets
hidden_dim  = Hidden dimension of teacher MLP -> Start small (e.g., 32), then tune (16/32/64/128).

# REINFORCE / variance reduction
use_baseline            = True
baseline_type           = "mean_return"      # or "value_function"
normalize_advantage     = True

# -----------------------------
# Main reward equation 
# -----------------------------

reward = validation_improvement - λ_cost * compute_cost - α_reg * stability_penalty

# -----------------------------
# Inputs / initialization
# -----------------------------
Full dataset = D

Split once:
    Training set D_tr = 80%
    Validation set D_val = 20% (half of it will be the holdout set)
    # stratified so each difficulty level appears in validation

Define buckets on training set:
    {I_k}_{k=1}^K
    # e.g. easy, medium, hard based on difficulty labels


Set hyperparameters (PoC): 
    episodes    = 100                           
    T           = 20        # start with 20-50 so the credit assignment is not hard with long horizons
    B           = 32        # or 64
    m           = 32          
    η_student   = 10^(-4)   # 0.99 is too high                           
    γ           = 0.95
    λ_cost      = 0 
    α_reg       = 0.0 
    p_ref       = uniform
    hidden_dim  = 32 - then if teacher not learning well (128)
    

Initialize running bucket statistics:
    avg_loss_per_bucket
    change_in_loss_per_bucket


Initialize:
    teacher -> parameters φ (one teacher through all episodes)

for each episode: 

    initialize student [ θ_0 ] (new student initialized for each episode) -> SEPARATE student model & optimizer for baseline AND curriculum
    for t in 0 ... T-1:

        # 1. Construct teacher observation
        o_t = (
            current step t,
            running average loss per bucket,
            running change in loss per bucket
        )

        # 2. Teacher chooses action (distribution over buckets) -> teacher policy μ_φ(. | o_t) 
        logits_t = TeacherMLP_φ(o_t)
        teacher_probs_t = softmax(logits_t)                             # teacher_probs_t is the mean/preferred bucket distribution
        concentration_t = concentration_scale * teacher_probs_t + ε     # concentration_scale controls how noisy/exploratory the sampled action is
        a_t ~ Dirichlet(concentration_t)                                # a_t is the actual sampled distribution over buckets used at this step
        log_prob_t = log Dirichlet(a_t ; concentration_t)               # stored for the REINFORCE update


        # 3-4. Sample training mini-batch B_t from D_tr using a_t
        training_batch = []
        for b in 1 ... B: # for each example in the batch
            sample bucket k_{t,b} ~ Categorical(a_t)            # Pick which bucket this example should come from.
            sample example index i_{t,b} ~ Uniform(I_{k_{t,b}}) # Then pick a random example inside that bucket.
            add example e_{i_{t,b}} to training_batch
            # so batch B matches the distribution dictated by a_t

        # 5. Sample one validation mini-batch from fixed D_val
        sample validation batch B̃_t of size m uniformly from D_val

        # 6. Compute validation loss BEFORE learner update
        val_loss_before = average SFT loss on B̃_t using θ_t

        # 7. Train learner on current training batch
        for each example in training_batch:
            student predicts answer
            compute SFT loss (cross-entropy against target)
            compute gradient w.r.t. θ_t
        average gradients across the B examples

        # 8. Learner update (SFT)
        θ_{t+1} = θ_t - η_student * averaged_gradient

        # 9. Update running bucket statistics (only for buckets that appeared in the current training batch) 
        compute per-bucket batch loss
        update running average loss per bucket
        update running change in loss per bucket

        # 10. Compute validation loss AFTER learner update
        val_loss_after = average SFT loss on SAME validation batch B̃_t using θ_{t+1}

        # 11. Compute reward
        validation_improvement = val_loss_before - val_loss_after
        compute_cost = c(training_batch)
        stability_penalty = KL(a_t || p_ref)

        r_t = validation_improvement - λ_cost * compute_cost - α_reg * stability_penalty

        store r_t in trajectory
        store log_prob_t = log μ_φ(a_t | o_t) in trajectory (REINFORCE is episodic)

    # End training -> episode ended (because you accumulate then update)
    
    for t in range(T): # Compute all returns 
        q_t = sum_{k=t}^{T-1} γ^{k-t} r_k       # r_k = reward at time step k
    
    episode_baseline = mean (q_0, q_1, ..., q_{T-1})    # over the steps in an episode
    for t in range(T): 
        A_t = q_t - episode_baseline                    # computing the avantage 
    
    # Compute policy gradient
    total_gradient = 0
    for t in range(T):
        total_gradient += ∇_φ log μ_φ(a_t | o_t) * A_t 

    # 12. Teacher update once per episode using all stored log_probs and rewards
    φ ← φ + η_teacher * total_gradient

# ---------------------------------------------------------------------------------------
So the full loop is:
- Buckets hold lists of training examples grouped by level.
- Teacher outputs probabilities over buckets.
- Batch sampler picks bucket indices using those probabilities.
- Sampler picks concrete examples from those buckets.
- Student trains on those examples.
- Losses are aggregated back by bucket.
- Teacher sees updated bucket stats and adjusts future probabilities.

# ---------------------------------------------------------------------------------------
After sampling the training_batch -> the big picture becomes: 
- training_batch = which examples we used
- sampled_bucket_indices = which bucket each example came from
- per_example_losses = how hard each example was for the student
- update_bucket_loss_stats = compress all that into per-bucket difficulty signals

# -----------------------BUILDING the observation o_t -----------------------------------
    - batch_avg_loss
        - average loss for a bucket in just the current batch
        - noisy but very fresh
    - running_avg_loss
        - smoothed version across many steps
        - more stable, less noisy
    - And loss_change
        - how much running_avg_loss moved this step
        - tells the teacher not just “how hard is this bucket?” but also “is it improving or getting worse?”


# ----------------------- NEW SETUP -----------------------------------
- one episode = one rollout / one trajectory
- inside that episode, the student trains for teacher_train_steps steps
- across those steps, you collect rewards and log_probs
- then at the end of the episode, you do one REINFORCE update to the teacher
